Privacy Policy

Last updated: 2026-09-27

Sync is a personal utility used to synchronize files between a computer and Drive.

Information accessed

The application accesses Drive files and folders only when authorized by the user. This access is used solely to perform file synchronization.

How information is used

The data is used only for the application's synchronization functionality. The application does not sell, rent, or use the data for advertising.

Data storage

The application does not operate a separate online backend. Files are synchronized between the user's computer and the user's account using the user's own configuration.

Data sharing

Data is not shared with third parties by this application.

Revoking access

The user can revoke the application's Drive access at any time from their Account security settings.

Contact

For privacy questions, contact the project owner through the contact information associated with this GitHub repository.
